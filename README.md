# Syed Khunmeer — Portfolio

An Apple-inspired personal portfolio experience built with semantic HTML, CSS, and vanilla JavaScript. The hero sculpture is rendered with a lightweight canvas animation so the site has no build step or dependency tree.

## Run locally

From this folder, start any static file server:

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080). The site can also be opened directly through `index.html`, though a local server is recommended for consistent browser behavior.

## Customize

- Add real GitHub, LinkedIn, and email details in the contact section of `index.html`.
- Adjust visual tokens and responsive breakpoints in `styles.css`.
- The interactive sculpture and reduced-motion handling live in `script.js`.

The site is deployable as a static folder on GitHub Pages, Netlify, Vercel, or any standard static host.
